# CRUD de Produtos com Flet

Aplicativo de gerenciamento de produtos desenvolvido em Python utilizando o framework Flet.

Este projeto foi desenvolvido como atividade acadêmica para demonstrar as operações de CRUD:

- Create (Criar)
- Read (Ler)
- Update (Atualizar)
- Delete (Deletar)

## Funcionalidades

- Cadastro de produtos
- Visualização dos produtos cadastrados
- Edição de produtos
- Exclusão de produtos
- Validação dos dados
- Armazenamento dos dados em arquivo JSON
- Persistência dos dados após fechar o aplicativo

## Tecnologias utilizadas

- Python
- Flet
- JSON
